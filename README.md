# crc16ccit_c_short
A C/C++ implementation of CRC16-CCIT calculating function based on implementation which can be found on the following website: https://srecord.sourceforge.net/crc16-ccitt.html

A python implementation can be found here:
  * https://github.com/sarukoushi/pycrc16ccit

Let me know if you see any problems/errors, or if the code could be improved.
